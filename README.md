# Math Experiments

Small computational experiments on open problems. These are exploratory scripts, not proofs: nothing here
claims to solve anything, and most of the code is terse because it was written to answer one question at a time.

See each folder's README for what it does. Python scripts use [PySAT](https://pysathq.github.io/).
My longer attempt on OEIS A060957 lives in its own repo, [OeisA60957](https://github.com/kahlio76/OeisA60957).
